# Windows 发布门禁

`G2-ready` 仅代表源码、模块协议和本机网页外壳完整；它不代表 Windows 自动化已可公开发布。以下项目全部通过前，OPT / LAB 只能作为本地开发构建。

## 必须完成

1. 在 Windows 10 22H2 x64、Windows 11 x64 的真实设备上编译并运行 WinUI/WebView2 宿主。
2. 使用公开可验证的代码签名证书签署安装器、`OptLab.App.exe` 与 `OptLab.Broker.exe`。
3. 安装并验证管理员 Broker 的启动方式、同用户 IPC ACL、UAC 提示、崩溃恢复和卸载前恢复检查。
4. 建立固定公钥、模块签名流水线和 HTTPS 更新清单；拒绝未签名、篡改和降级模块。
5. 对每一个写入规则完成“检测 → 快照 → 应用 → 独立验证 → 逆序恢复”实机测试。
6. 对完美平台或其他第三方软件，先记录真实进程、版本、配置来源、反作弊/平台兼容性和恢复结果；未获得证据前不得结束进程、改优先级或修改配置。
7. 验证选板可打开三个独立产品；优化工作台只包含诊断、恢复和设置，不再嵌 iframe 工具。
8. 验证 `shell.ready → host.context` 握手、成功/失败回执、宿主超时降级；断开宿主时不得残留“Windows 已连接”或“已打开设置”的成功提示。

## 当前状态

- 网页壳、CS2 校准模块与投掷物瞄点：源码位于同级产品目录；本地浏览器验证待本次重构后回归。
- 开赛准备已从工作台移除；研究目录仍可作为资料，不挂界面。
- Windows App/Broker：源码已建立，等待 Windows 工具链与真机验收。
- 优化工作台：宿主能力分层、本机诊断页和恢复中心已实现；真实 WebView2 回执仍等待 Windows 验收。
- 自动化写入规则：未发布，默认拒绝。
